Wayfinder

The algorithm should be yours

Wayfinder is an independent on-device recommender algorithm for YouTube. It gives the user, not YouTube, total control over how the algorithm functions, and lets you see how recommendations are being made.

Designed for safety, not addiction

Separating the algorithm from the underlying platform completely changes the incentives around recommender algorithm design. It encourages developers to build tools users actually want to use instead of trying to keep them watching content for as long as possible.

We're asking regulators to make this possible.

Wayfinder is just a tech demo for now. We're calling on governments to mandate the software interfaces needed to open up genuine competition in the recommender algorithm space.
